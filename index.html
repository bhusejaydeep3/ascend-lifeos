About tactile feedback

iPhone Safari and Home Screen web apps do not expose a dependable public Taptic Engine API. ASCEND uses animated visual feedback and optional sound on iPhone, plus a best-effort native haptics bridge for a future native wrapper. Browsers that support the Vibration API can receive tactile taps.
